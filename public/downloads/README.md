# Downloads

Place downloadable files here. They'll be served at `/downloads/<filename>`.

## Current files referenced by the site

- `modem-de-carne.pdf` — Book: "Modem de Carne"
- `city-solutions-palette.pdf` — Paper: "City Solutions Palette"

To add a new download, drop the file into this folder and add a matching button in `public/index.html` inside the `.qbtns` block.
